# Jost\*

The font of the cover and the title page of the pocket dictionary.

Jost\* is the free revival of Paul Renner's **Futura**, drawn by
*indestructible type\**. The model supplied by the publisher of this
edition is set in Futura; Futura not being free, the cover is set in
Jost\*, which takes up its geometric drawing — a true circle, capitals
with wide counters, a single-storey `a`.

Three cuts are enough for the cover, and only those are here:

| file | use |
|---|---|
| `Jost-Bold.ttf` | *DICIONARIO*, the subtitle, *ID* |
| `Jost-Medium.ttf` | *Marcelo Persiko*, *ex-membro di la Akademio* |
| `Jost-MediumItalic.ttf` | *(Marcel Pesch)* |

They are loaded **by path** (`Path=fonts/` in `cover.tex`), not by name:
the document therefore sets identically on a machine where Jost\* is not
installed. The rest of the book keeps its usual fonts, Charis SIL for the
text and Inter for the running heads.
