# Deux articles frappes a la suite sur une MEME ligne de la grille, sans le
# code de langues qui permet a la machine de les separer d'elle-meme (voir
# RE_DIVIDO dans outils/edition.py : la coupure s'appuie sur le « - DEFIS. »
# qui finit chaque article). Quand la dactylo a insere une note entre les deux,
# ce reperage tombe, et le second article se retrouve avale dans le premier.
#
# La cle est la ligne de la grille — image:ligno. Le second article commence a
# la chaine donnee, et il HERITE la ligne du premier : les deux ont bien ete
# frappes la, et le fac-simile le montrera.
#
# La dactylo a souligne « shovar » comme elle souligne les domaines : c'est
# ainsi qu'elle signale une vedette posee au milieu d'une ligne. Le mot manquait
# au dictionnaire, entre « shokar » et « shovelo », et son code de langues — DE,
# schieben et shove — finissait la ligne sans que rien le rattache a lui.
#
# cle	chaine ou commence le second article
532:29	shovar. (trans.) Glitigar per pulso
#
# Quatre autres, trouves de la meme facon : le code de langues finit bien
# l'article, mais ce qui suit ne se presente pas comme une vedette — une
# virgule au lieu du point chez « asasinar », un tiret d'affixe chez « ko- »,
# une parenthese egaree entre les deux chez « tino », rien du tout chez
# « warfo ». La dactylo, elle, les a tous soulignes.

288:47	ko- Prefixo ciencala qua signifikas
588:42	tino. Earelo di qua la fundo

# « si » porte deux articles : la note de musique, qui n'a pas de code de
# langues, et l'adverbe non officiel « *si » — celui que « yes » cite,
# « (yes ya = *si) » —, qui porte le « - F. » final. La dactylo les a frappes
# a la suite sans laisser de ligne, et le second commence par sa marque, non
# par une majuscule : le reperage automatique n'y voyait rien.
